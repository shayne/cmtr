# Repository Guidelines

## Project Structure & Module Organization
- `src/cmtr/`: Primary Python package; includes the CLI entry point (`cmtr:main`).
- `pyproject.toml`: Project metadata, dependencies, and build configuration (uv).
- `uv.lock`: Locked dependency set generated by uv.
- `mise.toml`: Tool versions and task shortcuts.
- `README.md`: User-facing documentation.
- `LICENSE`: MIT license.

## Build, Test, and Development Commands
Use mise for tool management and uv for environment execution.
- `mise install`: Install tool versions (Python via mise).
- `mise run install`: Create/update the uv environment with dev tools (`uv sync --group dev`).
- `mise run run`: Run the CLI in the project environment (`uv run cmtr`).
- `mise run lint`: Run Ruff lint checks (`uv run ruff check .`).
- `mise run format-check`: Check formatting with Ruff (`uv run ruff format --check .`).
- `mise run format`: Format code with Ruff (`uv run ruff format .`).
- `mise run test`: Run the pytest suite (`uv run pytest`).
- `mise run typecheck`: Run static checks (`uv run ty check`).
- `mise run build`: Build source and wheel distributions (`uv build`).

Direct uv equivalents:
- `uv sync --group dev`: Resolve and install dependencies into the uv environment.
- `uv run cmtr`: Execute the CLI in the uv environment.
- `uv run ruff check .`: Run lint checks.
- `uv run ruff format --check .`: Check formatting.
- `uv run ruff format .`: Format code.
- `uv run pytest`: Run tests.
- `uv run ty check`: Run type checks.
- `uv build`: Build distributions.

## Coding Style & Naming Conventions
- Language: Python (target 3.12+; see `.python-version` and `pyproject.toml`).
- Indentation: 4 spaces; no tabs.
- Naming: `snake_case` for functions/variables, `PascalCase` for classes.
- Formatting/linting: Ruff is configured via `pyproject.toml`; keep edits minimal and readable.

## Testing Guidelines
- Tests use `pytest` with `tests/test_*.py` naming.
- Run tests with `uv run pytest` or `mise run test`.
- Add focused regression tests for user-facing behavior changes and bug fixes.

## Commit & Pull Request Guidelines
- Recent commits use a Conventional Commits style (`feat:`, `chore:`). Follow the same prefix pattern for new commits.
- PRs should include: a concise summary, how to verify (commands/output), and linked issue/context if applicable.

## Configuration & Tooling Tips
- Update `pyproject.toml` when adding dependencies or CLI entry points.
- Keep `mise.toml` in sync with required tool versions and tasks.
- Regenerate `uv.lock` via `uv sync` when dependencies change.
- Always keep `README.md` up to date when adding, removing, or changing user-facing behavior.
